Emberline.

A puzzle-platformer built around one transferable flame.

01 / INTERACTIVE

The game

Emberline is a 2D puzzle-platformer in which the player carries a flame through a world whose platforms and mechanisms respond to light and darkness. The flame can be thrown or transferred, and its position changes the routes available through a level. Bridges, climbable vines, hidden platforms, and light-powered or dark-dependent mechanisms turn the flame into a tool the player must relocate deliberately.

I designed the demo around a small set of interactions that can be combined in different ways. Early sections introduce movement and flame use; later sections ask the player to manage the light's location while navigating obstacles and mechanisms.

02 / INTERACTIVE

Implementing flame ownership

I built a central FlameState system to track which object currently holds the flame. The player, a thrown flame, or a compatible mechanism can become the holder. Transfers pass through try_transfer(), updating the active holder and notifying other systems. This keeps flame ownership consistent as the player moves it between objects.

The illumination system follows the flame's world position, allowing nearby platforms, bridges, vines, and receivers to respond to the same shared state. The thrown-flame object handles outward movement, deceleration, transfer to a receiver, and return toward the player.

03 / INTERACTIVE

Building the level

I combined these components with walking, jumping, climbing, checkpoints, hazards, and audiovisual feedback. I also created dedicated test scenes for specific mechanisms so I could refine their behavior before incorporating them into the main level. The finished demo connects the interactions into one playable sequence with a clear endpoint.

04 / INTERACTIVE

Play

The desktop-browser demo is embedded below. Players can also open it in a separate tab. The project additionally has macOS and Windows builds.

PLAY THE DEMO

Play Emberline

Click inside the game to focus it. Use arrow keys to move and climb, Space to jump, hold Q to aim and release to throw the flame, F to pass it, E to interact, and R to restart. A desktop keyboard is recommended.
